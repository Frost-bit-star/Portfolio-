---

StackVerify handles messages across Email, SMS, and WhatsApp, letting users run basic campaigns and automation. It works reliably in everyday situations, helping messages reach their destination without fuss.

```js
// Example usage
sendMessage({
  platform: "whatsapp",
  to: "+254768974189",
  message: "Hello from StackVerify!"
});
```
